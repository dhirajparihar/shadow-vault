§ 03 / IMPLEMENTATION GUIDE

          
Drop-In Python Quickstart (12 Lines)

          

            Protect any Python function or agent tool in seconds. The decorator @vault_guard re-hydrates real PII right before your tool executes and sanitizes return values automatically.
          

        


        

          Dependencies:
          Zero heavy ML (pure Python)
        

      


      
      

        

          

            
            
            
            quickstart.py
          

          
        


        
# pip install shadow-vault
from shadow_vault import ShadowVault, vault_guard

vault = ShadowVault()

# 1. Protect your internal tool: automatically receives real PII, returns masked PII
@vault_guard(vault=vault, session_id_arg="session_id")
def charge_customer(email: str, card: str, session_id: str = "default") -> dict:
    # Tool executes with REAL PII: email='alice@example.com', card='4532 0151 1283 0366'
    return {"status": "PAID", "receipt": email, "backup_phone": "+91 9876543210"}

# 2. Dehydrate safe prompt for the Cloud LLM:
prompt = vault.dehydrate("Charge alice@example.com on card 4532 0151 1283 0366", session_id="s1")
# Prompt becomes: "Charge u_c09753@shadow.vault on card 4000009995970590" (Valid Luhn!)

# 3. Model executes tool with synthetic tokens -> returns sanitized output back to agent state:
result = charge_customer(email="u_c09753@shadow.vault", card="4000009995970590", session_id="s1")
# Result: {'status': 'PAID', 'receipt': 'u_c09753@shadow.vault', 'backup_phone': '+919000597059'}

      


    

  


  
  
  
  

    

      
      

        
§ 04 / RUNTIME PROTOCOL

        
Zero-Code Model Context Protocol (MCP) Gateway

        

          Wrap any existing MCP server (Node.js, Python, Go, Rust, SQLite) with a transparent stdio privacy proxy. Intercept JSON-RPC messages between Claude Desktop, Cursor, and your tools with zero application code changes.
        

      


      


        
        

          

            claude_desktop_config.json
            Claude Desktop & Cursor
          


          
{
  "mcpServers": {
    "secure-sqlite": {
      "command": "shadow-vault",
      "args": [
        "mcp-proxy",
        "--session-id", "claude_session",
        "--fail-closed",
        "--",
        "uvx", "mcp-server-sqlite", "--db", "customers.db"
      ]
    }
  }
}

          

            The proxy automatically swaps synthetic tokens back to real records when Claude executes a tool, and re-dehydrates results before sending them back to Anthropic.
          

        


        
        

          

            LangChain & LangGraph StateGraph
            Agentic Frameworks
